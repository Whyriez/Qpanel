# Installer

Direktori ini berisi skrip instalasi, pembaruan, dan uninstall Qpanel:
- `install.sh`: Skrip instalasi satu perintah untuk server baru (Ubuntu 22.04/24.04 LTS, Debian 12).
- `upgrade.sh`: Skrip upgrade binary panel dan migrasi skema database.
- `uninstall.sh`: Skrip pembersihan panel dari sistem host.
