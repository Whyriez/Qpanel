# Font antarmuka

Font variable Latin, bobot 400–700, di-host dari paket aplikasi:

- Plus Jakarta Sans: UI, Google Fonts (`ofl/plusjakartasans`).
- JetBrains Mono: path, kode, terminal; Google Fonts (`ofl/jetbrainsmono`).

WOFF2 berasal dari distribusi Google Fonts; lisensi OFL masing-masing disertakan.
Tidak ada request font ke CDN saat aplikasi digunakan. Karakter di luar subset
Latin menggunakan font fallback sistem.
